## L2 组件测试用例

### E10 轮播相册式（默认）

| 项 | 内容 |
|----|------|
| 操作 | 左右滑动浏览→点击删除/保留按钮 |
| 预期 | 居中大图+左右预览；滑动仅切换不触发操作；按钮操作后自动跳下一张 |

### E11 卡片左右滑

| 项 | 内容 |
|----|------|
| 前置 | 设置切到卡片模式 |
| 操作 | 左滑/右滑 |
| 预期 | 左滑标记删除（红色提示）；右滑保留（绿色）；卡片跟随手指旋转+透明度变化 |

### E12 全屏上下滑

| 项 | 内容 |
|----|------|
| 前置 | 设置切到全屏模式 |
| 操作 | 上下滑动→点击右侧按钮 |
| 预期 | 全屏展示；上下滑切换；悬浮按钮操作正常；底部文件信息显示 |

### E13 运行时切换模式

| 项 | 内容 |
|----|------|
| 操作 | 设置中切换交互模式→返回首页→开始新一轮 |
| 预期 | 新模式立即生效 |

### E14 主题实时切换

| 项 | 内容 |
|----|------|
| 操作 | 设置页横滑选择不同主题 |
| 预期 | 设置页立即切换为新主题配色 |

### E15 主题贯穿全页面

| 项 | 内容 |
|----|------|
| 操作 | 切换到"优雅暗黑"→依次进入首页/浏览页/结果页 |
| 预期 | 所有页面均使用暗黑主题色；文字对比度可读 |

### E16 5 套主题全量验证

| 项 | 内容 |
|----|------|
| 操作 | 逐一切换 5 套主题，每套走一遍完整清理流程 |
| 预期 | 所有页面配色、圆角、阴影、动效均匹配该主题定义 |

### E17 每轮数量调节

| 项 | 内容 |
|----|------|
| 操作 | 设置中数量改为 5→开始清理 |
| 预期 | 仅随机选取 5 张，进度显示 N/5 |

### E18 设置持久化

| 项 | 内容 |
|----|------|
| 操作 | 修改主题+模式+数量→杀 App→重新打开 |
| 预期 | 所有设置保持上次值 |

## L1 单元测试用例

### RandomPicker

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| U01 | 正常随机选取 | 100 媒体, count=10, exclude=[] | 返回 10 个不重复项 |
| U02 | 多次不重复 | 连续 2 次, count=10 | 两次无交集 |
| U03 | 数量不足 | 3 媒体, count=10 | 返回全部 3 个 |
| U04 | 空列表 | 0 媒体, count=10 | 返回空列表 |
| U05 | 去重后不足 | 15 媒体, count=10, exclude=10 个 | 返回 5 个 |
| U06 | 全已展示 | 10 媒体, exclude=全部 | 清空 exclude 重选 |
| U07 | count 边界 | count=5/10/15/20 | 各返回对应数量 |

### ThemeManager

| 编号 | 用例 | 预期 |
