## L4 端到端用例

### E01 完整照片清理流程

| 项 | 内容 |
|----|------|
| 前置 | 设备有 100+ 张照片 |
| 操作 | 首页→"随机清理照片"→浏览 10 张，保留 6/标记删除 4→结果页确认删除 |
| 预期 | 系统弹窗出现 1 次；确认后 4 张进入回收站；统计"删除4/保留6/释放X MB" |

### E02 再来一轮

| 项 | 内容 |
|----|------|
| 前置 | E01 完成 |
| 操作 | 点击"再来一轮" |
| 预期 | 新 10 张与上轮不重复；进度重置为 1/10 |

### E03 全部保留（→ 直接完成态）

| 项 | 内容 |
|----|------|
| 操作 | 10 张全部点击"保留" |
| 预期 | 无待删除项，结果页直接进入**完成态**：标题"本轮清理完成"可见；"删除 0 / 保留 10"；无确认删除按钮；无系统删除弹窗 |

### E04 全部删除（→ 待确认态 → 完成态）

| 项 | 内容 |
|----|------|
| 操作 | 10 张全标记删除→进入结果页（待确认态）→点击"确认删除"→系统弹窗确认 |
| 预期（待确认态） | 标题"即将删除 N 项"可见；**"本轮清理完成"不可见**；"确认删除"按钮与待删除列表可见；"删除后不可在 App 内撤销"提示可见 |
| 预期（完成态） | 删除成功后标题"本轮清理完成"可见；"确认删除"按钮与待删除列表消失；"已成功删除"提示可见 |
| 系统行为 | 系统弹窗 1 次；N 张进入回收站 |

> **回归要点**：本用例的核心新增断言是"待确认态下 `本轮清理完成` 不可见"——修复前正是因为缺这条断言，bug 才漏过 E2E。

### E05 结果页反悔

| 项 | 内容 |
|----|------|
| 操作 | 标记删除 4 张→结果页取消 2 张删除标记→确认 |
| 预期 | 仅 2 张被删除 |

### E06 系统弹窗取消

| 项 | 内容 |
|----|------|
| 操作 | 标记删除 4 张→结果页确认→系统弹窗点"取消" |
| 预期 | 所有照片保留；提示"已取消删除" |

### E-PRV-01 待删除项全屏预览：点击放大 + 左右滑（US-CP-24）

| 项 | 内容 |
|----|------|
| 前置 | 标记删除 ≥2 张 → 进入结果页待确认态 |
| 操作 | 点击待删除缩略图 → 全屏放大 → 左右滑切换 → 点「返回」 |
| 预期 | 全屏出现（返回按钮可见）；左右滑切换、进度变化；返回后列表与标记不变 |

### E-PRV-02 全屏内取消删除 + 删空退出（US-CP-24）

| 项 | 内容 |
|----|------|
| 前置 | 标记删除 N 张 → 结果页 → 点缩略图进全屏 |
| 操作 | 逐个点「取消删除」直到列表为空 |
| 预期 | 每次取消列表项数 -1；删空后全屏自动关闭，结果页回到统计（无待删除项） |

### E-PRV-03 视频待删除项全屏播放（US-CP-24）

| 项 | 内容 |
|----|------|
| 前置 | 视频清理标记删除若干 → 结果页 |
| 操作 | 点击待删除视频缩略图进入全屏 |
| 预期 | 视频自动播放、存在静音切换按钮；可缩放/返回 |
