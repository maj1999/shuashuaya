## L2 组件测试用例

### E10 轮播相册式（默认）

| 项 | 内容 |
|----|------|
| 操作 | 左右滑动浏览→点击删除/保留按钮 |
| 预期 | 居中大图+左右预览；滑动仅切换不触发操作；按钮操作后自动跳下一张 |

### E11 卡片左右滑

| 项 | 内容 |
|----|------|
| 前置 | 设置切到卡片模式 |
| 操作 | 左滑/右滑 |
| 预期 | 左滑标记删除（红色提示）；右滑保留（绿色）；卡片跟随手指旋转+透明度变化 |

### E12 全屏上下滑

| 项 | 内容 |
|----|------|
| 前置 | 设置切到全屏模式 |
| 操作 | 上下滑动→点击右侧按钮 |
| 预期 | 全屏展示；上下滑切换；悬浮按钮操作正常；底部文件信息显示 |

### E13 运行时切换模式

| 项 | 内容 |
|----|------|
| 操作 | 设置中切换交互模式→返回首页→开始新一轮 |
| 预期 | 新模式立即生效 |

### E14 主题实时切换

| 项 | 内容 |
|----|------|
| 操作 | 设置页选择"大胆几何"主题 |
| 预期 | 设置页立即变为深色背景 + 渐变色块风格，按钮/选择器跟随变化 |

### E15 主题贯穿全页面（含布局变化）

| 项 | 内容 |
|----|------|
| 操作 | 切换到"大胆几何"→依次进入首页/浏览页/结果页 |
| 预期 | 首页变为双卡片并排布局（非列表式）；浏览页按钮变为渐变填充；结果页统计为色块卡片；所有页面深色背景 |

### E16 5 套新主题全量验证

| 项 | 内容 |
|----|------|
| 操作 | 逐一切换 5 套主题（极简/几何/温暖/活泼/杂志），每套走一遍完整清理流程 |
| 预期 | 每个主题：闪屏→首页→浏览→结果→设置均使用对应主题的配色、圆角、图标风格和布局 |

### E17 每轮数量调节

| 项 | 内容 |
|----|------|
| 操作 | 设置中数量改为 5→开始清理 |
| 预期 | 仅随机选取 5 张，进度显示 N/5 |

### E18 设置持久化

| 项 | 内容 |
|----|------|
| 操作 | 修改主题+模式+数量→杀 App→重新打开 |
| 预期 | 所有设置保持上次值；闪屏也展示对应主题动画 |

### E20 矢量图标验证（无残留 emoji） — 新增

| 项 | 内容 |
|----|------|
| 操作 | 使用每个主题，遍历所有页面（首页、设置页、浏览页所有模式、结果页、空状态页） |
| 预期 | 所有操作图标均为矢量线条图标，无 emoji 字符残留（📷🎬⚙️🗑️🎉✨🖼️🃏📱🔄🏠⚠️🔇🔊▶ 均不出现） |
| 验证方式 | 代码扫描 + 视觉 screenshot 对比 |

### E21 每个主题独立布局验证 — 新增

| 项 | 内容 |
|----|------|
| 操作 | 逐一切换 5 个主题，在首页截图对比 |
| 预期 | 极简=分段切换+单按钮、几何=双卡片并排、温暖=列表卡片堆叠、活泼=毛玻璃卡片+图标网格、杂志=报头+双栏分栏 |
| 验证方式 | Maestro takeScreenshot 后人工确认，或通过 UI 元素断言验证布局特征 |

## L1 单元测试用例

### RandomPicker

| 编号 | 用例 | 输入 | 预期 |
|------|------|------|------|
| U01 | 正常随机选取 | 100 媒体, count=10, exclude=[] | 返回 10 个不重复项 |
| U02 | 多次不重复 | 连续 2 次, count=10 | 两次无交集 |
| U03 | 数量不足 | 3 媒体, count=10 | 返回全部 3 个 |
| U04 | 空列表 | 0 媒体, count=10 | 返回空列表 |
| U05 | 去重后不足 | 15 媒体, count=10, exclude=10 个 | 返回 5 个 |
| U06 | 全已展示 | 10 媒体, exclude=全部 | 清空 exclude 重选 |
| U07 | count 边界 | count=5/10/15/20 | 各返回对应数量 |

### ThemeManager

| 编号 | 用例 | 预期 |
|------|------|------|
| U08 | 默认主题 | currentTheme.id == "warm"，layoutId == ThemeLayoutId.WARM |
| U09 | 切换主题 | Token 值全部匹配目标主题，layoutId 正确 |
| U10 | 主题持久化 | 重启后保持 |
| U11 | Token 完整性 | 5 套新主题无 null Token，所有枚举字段有效 |
| U15 | 旧主题 ID 迁移 | switchTheme("dreamy-gradient") → 回退到 "warm" 默认主题 |

### AppSettings

| 编号 | 用例 | 预期 |
|------|------|------|
| U12 | 默认值 | theme=warm, mode=carousel, count=10 |
| U13 | 写入读取 | roundCount=20→读取==20 |
| U14 | 非法值防御 | roundCount=99→回退默认值 10 |
