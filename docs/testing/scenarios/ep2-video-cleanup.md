## L4 端到端用例

### E07 完整视频清理流程

| 项 | 内容 |
|----|------|
| 前置 | 设备有 20+ 个视频 |
| 操作 | 首页→"随机清理视频"→浏览视频→（全保留或标记删除）→进入结果页 |
| 预期 | 视频缩略图+时长正确显示；流程与照片一致 |
| 完成态断言 | 进入完成态后标题"本轮清理完成"可见（验证视频路径复用同一两阶段结果页） |

### E08a 轮播模式视频预览播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 轮播模式下查看视频 |
| 操作 | 1. 验证视频缩略图上显示 ▶ 播放图标 2. 点击 ▶ 图标 3. 验证静音按钮 🔇 可见 4. 点击 🔇 切换为 🔊 |
| 预期 | 点击后视频在卡片内联播放（默认静音）；静音按钮可切换 |

### E08b 卡片模式视频预览播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 卡片滑动模式下查看视频 |
| 操作 | 1. 验证视频缩略图上显示 ▶ 播放图标 2. 点击 ▶ 图标 3. 验证静音按钮 🔇 可见 4. 点击 🔇 切换为 🔊 |
| 预期 | 点击后视频在卡片内联播放（默认静音）；静音按钮可切换 |

### E09 全屏视频自动播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 全屏模式下 |
| 操作 | 1. 滑到视频项 2. 验证自动播放 3. 验证静音按钮 🔇 可见 4. 点击切换 |
| 预期 | 自动静音播放；底部静音按钮可切换声音 |

### B02 视频为空

| 项 | 内容 |
|----|------|
| 前置 | 设备无任何视频 |
| 操作 | 点击"随机清理视频" |
| 预期 | 空状态页："没有视频" + 返回按钮 |

### B05 视频播放失败

| 项 | 内容 |
|----|------|
| 前置 | 含无法解码的视频 |
| 操作 | 滑到该视频 |
| 预期 | 占位图 + "无法播放此视频" + "跳过"按钮 |

### L4 端到端用例

> 实现：`maestro/flows/direct/video/fullscreen-video-scrubber.yaml`。导航前先切「视频」Tab（首页分页）、可选关闭更新弹窗。

| 编号 | 前置 | 操作 | 预期 |
|------|------|------|------|
| E-SCRUB-01 | 轮播模式，视频，已进全屏 | 观察底部 | `video_scrubber` 可见，随播放推进，显示当前/总时长 |
| E-SCRUB-02 | 全屏视频进度条已显示 | 拖动 `video_scrubber` 到靠右松手 | 播放位置跳转到对应时间（真机/adb 拖拽实证 seek 到 0:04） |
| E-SCRUB-03 | 轮播小卡播放视频（未进全屏） | 观察 | `video_scrubber` 不可见（仅全屏显示） |
| E-AUD-01 | 轮播视频播放并取消静音 → 点击进全屏 | 听声/查播放器 | 仅一个播放器发声，无重复叠加（logcat：底层 ExoPlayer 进全屏即 Release） |
| E-AUD-02 | 轮播取消静音 → 进全屏 | 观察全屏静音图标 | 显示有声（🔊），声音连续不中断 |
