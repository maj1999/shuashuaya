# CleanPic (刷刷鸭) — Logo 设计规范

|文档状态| 定稿 | 2026-04-05 |

## 设计概述

基于 [SVG Repo Small Duck](https://www.svgrepo.com/svg/117055/small-duck)（公共领域授权）的鸭子轮廓，改为品牌暖色调，搭配消散照片/视频卡片 + sparkle 闪光标记，传达"可爱的鸭子帮你清理照片和视频"的品牌含义。

## 设计方向

- **风格**：抽象符号，基于专业鸭子矢量素材
- **核心概念**：鸭子（品牌名"刷刷鸭"）+ 清理（消散的照片/视频）+ 焕新（sparkle）
- **配色**：跟随默认主题暖色调
- **用途**：全套品牌（App 图标 / 闪屏 / 应用商店头图 / 水印）

## 核心元素

### 1. 鸭子主体

素材来源：`https://www.svgrepo.com/svg/117055/small-duck`（CC0 公共领域，可自由商用和修改）

鸭子轮廓由 3 个 path 组成：
- **身体**（主路径）：包含头部、身体、整体轮廓
- **嘴巴**（独立路径）：左下方的嘴部区域
- **尾巴花纹**（独立路径）：尾部装饰

附加元素：
- **眼睛**：深棕色圆形 + 白色高光
- **腮红**：淡珊瑚色椭圆，低透明度

### 2. 消散照片/视频卡片

鸭子右上方散落 2-3 张矩形卡片，从实到虚（opacity 从 0.7 递减到 0.2），表达"正在被清理"。

- 照片卡片：白色圆角矩形 + 浅暖色填充
- 视频卡片：照片卡片 + 播放三角（▶）标识

### 3. Sparkle 闪光标记

2-3 个八角星形（大/中/小），表达"清洁焕新"，位于右上角区域。

## 使用场景

### App 图标

- 圆角方形裁切（iOS/Android 系统自动 mask）
- 鸭子居中，消散照片 + sparkle 保留
- 背景使用渐变色填充

### 闪屏

- 鸭子居中放大
- 下方展示品牌名"刷刷鸭"（字体：PingFang SC / Hiragino Sans GB，600 weight）
- 英文副标题"CleanPic"（可选）

### 应用商店头图

- 鸭子偏左放置
- 右侧展示品牌名 + 功能关键词（如"随机清理照片和视频"）

### 水印

- 单色版鸭子轮廓（无填色，纯描边）
- 低透明度（10-15%）

## 尺寸适配

| 尺寸 | 版本 | 包含元素 |
|------|------|---------|
| >= 64px | 完整版 | 鸭子 + 2-3 张消散照片 + 2-3 个 sparkle |
| 48px | 简化版 | 鸭子 + 1 张照片 + 1 个 sparkle |
| <= 32px | 最简版 | 仅鸭子轮廓（无照片、无 sparkle） |
