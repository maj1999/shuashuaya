## L4 端到端用例

### E07 完整视频清理流程

| 项 | 内容 |
|----|------|
| 前置 | 设备有 20+ 个视频 |
| 操作 | 首页→"随机清理视频"→浏览 10 个视频→标记删除若干→确认 |
| 预期 | 视频缩略图+时长正确显示；流程与照片一致 |

### E08 视频预览播放（轮播/卡片模式）

| 项 | 内容 |
|----|------|
| 前置 | 轮播或卡片模式下查看视频 |
| 操作 | 点击视频缩略图 |
| 预期 | 视频在当前位置内联播放，显示进度条；再次点击暂停 |

### E09 全屏视频自动播放

| 项 | 内容 |
|----|------|
| 前置 | 全屏模式下 |
| 操作 | 滑到视频项 |
| 预期 | 自动静音播放；点击画面切换声音；底部显示播放进度 |

### B02 视频为空

| 项 | 内容 |
|----|------|
| 前置 | 设备无任何视频 |
| 操作 | 点击"随机清理视频" |
| 预期 | 空状态页："没有视频" + 返回按钮 |

### B05 视频播放失败

| 项 | 内容 |
|----|------|
| 前置 | 含无法解码的视频 |
| 操作 | 滑到该视频 |
| 预期 | 占位图 + "无法播放此视频" + "跳过"按钮 |
