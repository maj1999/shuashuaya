# CleanPic — 产品需求文档

|文档状态| 初稿 | 2026-03-28 |

## 产品定位

CleanPic 是一款面向女性用户的相册随机清理工具 App。用户在碎片时间打开 App，随机浏览若干张照片或视频，轻松决定去留，释放手机存储空间。

## 目标用户

- 手机相册积累了大量照片/视频，想清理但不知从何下手的用户
- 偏好精致、有设计感的工具类 App 的女性用户
- 使用 Android、iOS 或鸿蒙手机的用户

## 核心价值主张

- **随机化**：不用翻遍相册，随机挑选一小批，降低决策负担
- **轻量化**：一轮只看若干张（默认 10 张），碎片时间即可完成
- **美观化**：5 套精美主题 + 3 种交互方式，让清理过程也是愉悦的体验

## 功能范围（V1.0）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 随机照片清理 | P0 | 随机选取 N 张照片逐一浏览，决定保留或删除 |
| 随机视频清理 | P0 | 随机选取 N 个视频逐一浏览，决定保留或删除 |
| 5 套主题样式 | P0 | 梦幻渐变(默认)/柔和极简/可爱活泼/优雅暗黑/自然温暖 |
| 3 种交互模式 | P0 | 轮播相册式(默认)/卡片左右滑/全屏上下滑 |
| 每轮数量可配置 | P1 | 5/10/15/20 张可选，默认 10 |
| 批量延迟删除 | P0 | 浏览时仅标记，结果页统一确认删除 |
| 再来一轮 | P0 | 一轮结束后可继续，自动去重 |

## 页面清单

详见 [User Stories](user-stories/README.md)。

| 页面 | 作用 |
|------|------|
| 启动页 | Logo + 主题色动画，1-2 秒 |
