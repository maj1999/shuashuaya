## L4 端到端用例

### E19a 轮播模式中途退出

| 项 | 内容 |
|----|------|
| 前置 | 轮播模式（默认），设备有照片或视频 |
| 操作 | 1. 首页→"随机清理照片" 2. 浏览若干张后点击 ProgressHeader 中的"← 退出" |
| 预期 | 立即回到首页；不进入结果页 |

### E19b 卡片模式中途退出

| 项 | 内容 |
|----|------|
| 前置 | 卡片滑动模式，设备有照片或视频 |
| 操作 | 1. 设置→切换到卡片模式→返回 2. 首页→"随机清理照片" 3. 浏览若干张后点击"← 退出" |
| 预期 | 立即回到首页；不进入结果页 |

### E19c 全屏模式中途退出

| 项 | 内容 |
|----|------|
| 前置 | 全屏模式，设备有照片或视频 |
| 操作 | 1. 设置→切换到全屏模式→返回 2. 首页→"随机清理照片" 3. 浏览若干张后点击 TopBar 中的"← 退出" |
| 预期 | 立即回到首页；不进入结果页（已有功能，回归验证） |
