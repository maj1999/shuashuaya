## 一、全局变更：ProgressHeader 新增退出按钮

**影响范围**：轮播模式、卡片模式共用的顶部进度栏（`ViewerScreen.ProgressHeader`）

**当前**：

```
┌─────────────────────────────────────────┐
│  3 / 10                                 │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
└─────────────────────────────────────────┘
```

**改后**：

```
┌─────────────────────────────────────────┐
│  ← 退出                       3 / 10   │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  │
└─────────────────────────────────────────┘
```

**规格**：

| 元素 | 规格 |
|------|------|
| "← 退出" 按钮 | TextButton，字号 14sp，颜色 `theme.colorTextSecondary` |
| 位置 | Row 左侧，与进度数字 `3 / 10` 两端对齐 |
| 点击行为 | `router.popBackStack()` 回到首页 |
| 最小触控区域 | 44x44dp（WCAG） |

**全屏模式不受影响**：已有 TopBar 中的 "← 退出"，保持现状。

**新增元素**：

| 元素 | 规格 |
|------|------|
| 🔇/🔊 静音按钮 | TextButton，字号 18sp，位于 FileInfoOverlay 右侧 |
| 位置 | 文件信息行末尾，与文件大小同行，`Spacer(weight=1f)` 推到右侧 |
| 默认状态 | 静音 `isMuted = true` |
| 显示条件 | 仅 `isPlaying == true` 且 `media.type == VIDEO` 时显示 |
| 点击行为 | 切换 `isMuted` |

### 状态切换逻辑

```
视频项进入视野
    │
    ├─ 显示缩略图（MediaImage）+ DurationBadge + PlayButton
    │
    ├─ 用户点击 ▶
    │     → isPlaying = true
    │     → 替换为 VideoPlayerView（默认静音）
    │     → 隐藏 PlayButton 和 DurationBadge
    │     → FileInfoOverlay 中显示 🔇 按钮
    │
    ├─ 用户切换到下一项（markKept/markDelete）
    │     → 自动 isPlaying = false（ExoPlayer 释放）
    │
    └─ 用户点击 🔇/🔊
          → 切换 isMuted
```

## 五、组件规格汇总

### 新增组件

| 组件 | 位置 | 规格 |
|------|------|------|
| **PlayButtonOverlay** | CarouselMode.MainCard / SwipeCardMode.CardContent 中央 | 48dp 圆形，黑底半透明 `alpha=0.4f`，白色 ▶ 图标 `alpha=0.8f`，字号 24sp |
| **退出按钮** | ViewerScreen.ProgressHeader 左侧 | TextButton "← 退出"，14sp，`theme.colorTextSecondary` |

### 复用组件（已有）

| 组件 | 说明 |
|------|------|
| `VideoPlayerView` | expect/actual 跨平台视频播放，接受 `isMuted` 参数 |
| `DurationBadge` | 时长角标，视频播放时隐藏 |
| `FileInfoOverlay` | 文件信息叠层，需扩展支持静音按钮 |

### 状态定义

| 状态变量 | 作用域 | 类型 | 默认值 |
|---------|--------|------|--------|
| `isPlaying` | 每个卡片（随 currentIndex 重置） | `Boolean` | `false` |
| `isMuted` | 每个模式组件级 | `Boolean` | `true` |
