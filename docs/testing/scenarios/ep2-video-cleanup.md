## L4 端到端用例

### E07 完整视频清理流程

| 项 | 内容 |
|----|------|
| 前置 | 设备有 20+ 个视频 |
| 操作 | 首页→"随机清理视频"→浏览 10 个视频→标记删除若干→确认 |
| 预期 | 视频缩略图+时长正确显示；流程与照片一致 |

### E08a 轮播模式视频预览播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 轮播模式下查看视频 |
| 操作 | 1. 验证视频缩略图上显示 ▶ 播放图标 2. 点击 ▶ 图标 3. 验证静音按钮 🔇 可见 4. 点击 🔇 切换为 🔊 |
| 预期 | 点击后视频在卡片内联播放（默认静音）；静音按钮可切换 |

### E08b 卡片模式视频预览播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 卡片滑动模式下查看视频 |
| 操作 | 1. 验证视频缩略图上显示 ▶ 播放图标 2. 点击 ▶ 图标 3. 验证静音按钮 🔇 可见 4. 点击 🔇 切换为 🔊 |
| 预期 | 点击后视频在卡片内联播放（默认静音）；静音按钮可切换 |

### E09 全屏视频自动播放+静音

| 项 | 内容 |
|----|------|
| 前置 | 全屏模式下 |
| 操作 | 1. 滑到视频项 2. 验证自动播放 3. 验证静音按钮 🔇 可见 4. 点击切换 |
| 预期 | 自动静音播放；底部静音按钮可切换声音 |

### B02 视频为空

| 项 | 内容 |
|----|------|
| 前置 | 设备无任何视频 |
| 操作 | 点击"随机清理视频" |
| 预期 | 空状态页："没有视频" + 返回按钮 |

### B05 视频播放失败

| 项 | 内容 |
|----|------|
| 前置 | 含无法解码的视频 |
| 操作 | 滑到该视频 |
| 预期 | 占位图 + "无法播放此视频" + "跳过"按钮 |
